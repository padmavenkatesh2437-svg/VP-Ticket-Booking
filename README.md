# VP Ticket Booking

React + Bootstrap ticket booking website (Flight, Cab, Bus, Train).

## Run
    npm install --legacy-peer-deps
    npm start        # opens http://localhost:3000

## Features
- Search by source, destination, date, passengers
- Sign up / Sign in (browser localStorage - demo only)
- Book ticket -> My Bookings page -> Cancel ticket
- FAQ, Contact form, responsive navbar

## Folder guide
- src/data.js        cities, operators and prices
- src/store.js       users and bookings saved in localStorage
- src/Component/     Navbar, Home, Booking, Auth, MyBookings, Faq, Contactus, Footer
